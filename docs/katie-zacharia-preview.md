# Katie Zacharia full-video test preview

The workflow `.github/workflows/publish-katie-zacharia-preview.yml` is a manually dispatched, opt-in path for the October 13, 2026 White House media briefing. It runs only from `main` on a GitHub-hosted runner. It does not modify or publish the original draft source intake.

The workflow finds the source draft in the paginated releases listing and pins release ID `413291052`, tag, asset ID `642103215`, name, size, and SHA-256. The isolated `fetch-source` job tests the runner's release-asset access with `contents: write`, verifies the downloaded bytes and media metadata, then passes the verified source bundle to the render job in a private, one-day Actions artifact. This permission is not granted to the long-running render job, which has only `contents: read` and `actions: read`; those permissions cover checkout and retrieval of the one-day source bundle and prior subtitle artifact. Before source processing the workflow requires exact-event and reuse-rights confirmations, checks the official White House event listing and copyright policy over HTTPS, and rejects video below 1920x1080 rather than upscaling. It uses `scripts/process_full_video.py` with the local runner ASR/translation pipeline and FFmpeg; no paid model API or voice cloning is used.

The workflow now offers two mutually exclusive dispatch modes after the same exact-event and reuse-rights confirmations. `private_review_only` verifies the pinned source asset, downloads the bilingual subtitle artifact from run `38661270142`, and requires that artifact's event identity and input SHA-256 match the exact verified source before reuse. It uses `--reuse-subtitles` to render the corrected style without rerunning ASR or machine translation; a missing or mismatched artifact fails closed. The private mode extracts rendered-frame samples at the beginning, midpoint, end, and densest bilingual cue, then uploads the rendered MP4, subtitles, frames, manifest, source verification, and operation audit as a private Actions artifact. It does not create or upload a Release, mutate the Pages catalog, or deploy Pages. The existing `publish_test_preview` mode remains an explicitly gated public prerelease and Pages deployment with its original ASR/translation path. ASR accuracy, Chinese translation, source audio/frame match, and complete visual/readability review remain `not_verified`; sampled frames are evidence for manual review, not proof that review passed. The White House copyright policy describes government-produced content as generally not copyright protected but notes transferred and third-party exceptions, which the workflow does not independently clear. Do not treat either mode as an approved final release.

The homepage's module-two cards are sorted by event date and link to the event-specific [source and version-confidence page](../events/katie-zacharia-2026-10-13/sources.html), which displays preview provenance and up to ten registered candidates. The list is a static catalog snapshot: it does not implement live YouTube discovery, daily latest-event prioritization, separate source runners, or evening cross-source checks. Candidate order pins the official event anchor, then uses event-match status, explicitly recorded embedded-banner/logo status, pixel resolution, duration, and view count. Missing values are not inferred; stable ties retain catalog order. Embedded graphics are not the same as obstruction: occlusion status is displayed separately and remains unassessed unless the evidence says otherwise. No comparable source-trust scoring scale has been defined, so trust scores remain visibly unassigned and do not affect rank. This is a display-ranking policy, not an independent verification/quality score; the current candidates have no confirmed clean-frame result.

The Katie workflow selects the opt-in `katie-fixed-lower-third-zh-first` layout in `scripts/process_full_video.py`: a fixed full-width, 20.5%-height opaque lower-third backing on the subtitle derivative, flush to the bottom edge; Chinese is above and at least 1.20x the English font size. The absolute font sizes are reduced from the earlier oversized preview while retaining the 82%-width text-safe area. Both language rows use fixed anchors; one line is preferred and up to two are allowed per language. Text is never shortened to fit: if a cue cannot be laid out within two bounded lines at safe word/punctuation boundaries, processing fails and the cue needs phrase-level review. The backing covers the full source banner region at the bottom while leaving the original source video intact; this is not a clean-source claim. The existing preview and screenshot predate this layout correction and have not been rerendered under it. Any future run still requires the workflow's exact-event and reuse-rights confirmations, and its rendered-frame review remains `not_verified` until reviewed from runner-produced frames.
